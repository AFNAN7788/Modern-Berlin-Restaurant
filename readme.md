# &#x20;         **Modern Berlin Restaurant**



A modern and responsive restaurant website built using HTML, CSS, JavaScript, Bootstrap, node.js and react.js. The project provides an elegant user interface for showcasing the restaurant, menu, gallery, reservations, and contact information.







✨ Features



* &#x20;🍽️ Responsive Restaurant Website
* &#x20;📋 Interactive Food Menu
* &#x20;📅 Table Reservation Form
* &#x20;💬 Customer Support
* &#x20;📞 Contact Section
* &#x20;📱 User Friendly Design
* &#x20;⚡ Smooth Animations







🛠️ Technologies Used



* &#x20;HTML5
* &#x20;CSS3
* &#x20;JavaScript
* &#x20;Bootstrap 5
* &#x20;Node.js
* &#x20;React.js
* &#x20;Express.js 





🚀 How to Run



Step 1:



Clone the repository.





git clone https://github.com/AFNAN7788/Berlin-Restaurant-Website.git



Step 2:





Move into the project folder and open terminal and run this command:





cd Berlin-Restaurant-Website







📚 Website Pages



Home



Displays the restaurant introduction and featured sections.



About



Provides information about the restaurant.



Menu



Displays food and beverage items.



Gallery



Shows restaurant images.



Reservation



Allows customers to book a table.



Contact



Contains contact information and Google Maps location.
